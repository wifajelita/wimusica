# Wimusikal — Collection Update

Updated Wimusikal landing page with a centered, polished Latest Collection section and four original SVG artworks.

## Files
- `index.html`
- `style.css`
- `script.js`
- `assets/collections/*.svg`

The collection artwork files were created specifically for this project as original vector illustrations. They are local assets, so the page does not depend on image hotlinks and should not show broken images.

## Music
The player expects these optional local files:
- `music/moment-of-peace.mp3`
- `music/cool-jazz-loops.mp3`
- `music/soft-afternoon.mp3`
- `music/good-energy.mp3`

Keep your existing `music/` folder when replacing the website files.
